# 04 · 多机协同（micro-ROS 核心价值）

> micro-ROS 的最大价值：一台 PC 统一调控多台机器人（一控多）。

## 一、为什么 micro-ROS 适合多机

```
传统多机器人：每台要一台电脑跑 ROS2（贵、重、贵功耗）
micro-ROS 多机器人：每台只要 ESP32（¥10）+ 一个 Agent 容器
→ 成本/重量/功耗大幅降低
```

## 二、多机架构

```
PC（Agent 池）
  ├─ Agent 1 → ESP32 机器人1
  ├─ Agent 2 → ESP32 机器人2
  ├─ Agent 3 → ESP32 机器人3
  └─ ...
→ 一台 PC 统一调控整个集群
```

## 三、关键技术

### Agent 容器化
```
每个 ESP32 一个 Agent 容器（Docker）：
  devices.txt: 每行一个设备
  容器：microros_ + 设备名
  ROS_DOMAIN_ID 隔离：11/22/33...
```

### ROS_DOMAIN_ID 隔离
```
每个机器人用不同 domain：
  机器人1: ROS_DOMAIN_ID=11
  机器人2: ROS_DOMAIN_ID=22
→ 独立命名空间，互不干扰
```

### 统一调控
```
PC 发布指令 → 各 Agent → 各机器人执行
机器人数据 → 各 Agent → PC 汇总
→ 集群编队/分布式任务
```
