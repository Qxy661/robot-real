## 二、YOLO 摄像头方案（待定）

### 情况
- 产品手册/源码有 leap_cam（ESP32 摄像头），但**本版本实机不带**
- 客服确认中：**是否留有接口可控摄像头二次开发**

### 方案 A：复用控制板接口（客服确认后）
```
如果控制板留有摄像头接口（I2C/SPI/CSI）
→ 加装 ESP32 摄像头模组 / 相机
→ 复用 leap_cam 固件 → MJPEG 流 → PC YOLO
```

### 方案 B：独立 USB 摄像头（最可行）
```
USB 摄像头插虚拟机/上位机
→ OpenCV 读流 → 发布 /camera/image_raw → YOLO
优点：即插即用，不依赖小车硬件
```

### 方案 C：小车摄像头 + PC 处理
```
如果留接口，可加摄像头模组
→ 小车采集 → WiFi 传 PC → YOLO
```

### 推荐：方案 B（USB 摄像头，独立）
```
最简单、最可靠、不依赖客服确认
USB 摄像头 → OpenCV → ROS2 话题 → YOLO
```
