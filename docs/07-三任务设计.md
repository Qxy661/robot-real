# 实机三任务细节设计

> 三任务递进：巡检（能做事）→ 巡逻（会自主）→ 语音（懂人话）。
> 体现作品集深度：从基础能力到自主到交互。

## IDEA 1：室内目标巡检（能做事）

### 流程
```
1. 建图（Cartographer）→ 保存地图
2. 用户指定目标（如"去桌子"）
3. Nav2 导航到目标区域
4. YOLO 检测确认目标物
5. 报告位置（坐标/语音）
```

### 模块
| 模块 | 技术 | 说明 |
|---|---|---|
| 建图 | Cartographer | 室内地图 |
| 导航 | Nav2（A* + DWA）| 到目标 |
| 检测 | YOLO | 确认目标 |
| 报告 | 位置/日志 | 输出坐标 |

### 验收
小车到目标 + 检测确认 + 报告位置

## IDEA 2：自主避障巡逻（会自主）

### 流程
```
1. 加载地图 → 设巡逻点序列
2. 依次巡逻（Nav2 多点导航）
3. 动态避障（局部规划器 DWB/MPPI）
4. 检测异常（YOLO）
5. 停靠报告
```

### 模块
| 模块 | 技术 | 说明 |
|---|---|---|
| 巡逻 | Nav2 多点 | 点序列 |
| 避障 | DWB/MPPI | 动态障碍 |
| 异常检测 | YOLO | 检测异常 |
| 报告 | 停靠+日志 | 完成巡逻 |

### 验收
自主巡逻多目标 + 避障 + 报告

## IDEA 3：语音指令控制（懂人话）

### 流程
```
1. 语音（ASR）→ 文字
2. VLA（Qwen3-VL）→ 任务序列
3. 执行（Nav2 导航 + YOLO 检测）
4. 反馈（TTS 报告）
```

### 模块
| 模块 | 技术 | 说明 |
|---|---|---|
| ASR | Whisper | 语音→文字 |
| VLA | Qwen3-VL | 指令→任务 |
| 执行 | Nav2 + YOLO | 导航+检测 |
| TTS | 语音合成 | 报告结果 |

### 验收
语音指挥小车执行 + 语音反馈

## 递进关系

```
IDEA 1：基础能力（建图+导航+检测）——能做事
IDEA 2：自主性（巡逻+避障）——会自主
IDEA 3：交互（语音+VLA）——懂人话
= 完整智能机器人能力证明
```

## 实现顺序

```
IDEA 1 → 先跑通（基础能力，最快）
IDEA 2 → 加自主（巡逻+避障）
IDEA 3 → 加交互（语音+VLA，最复杂）
```

## 依赖

- IDEA 1：建图导航（阶段2）+ YOLO（K230/PC）
- IDEA 2：IDEA 1 + 局部规划器对比
- IDEA 3：IDEA 1/2 + ASR + VLA（Qwen3-VL）
