# 实机架构与启动（LEAP 上位机研究）

> 基于 xuegeros_ws 源码研究（2026-08-04）。实机操作的基础。

## 一、上位机完整栈（xuegeros_ws）

```
xuegeros_ws/src/
├── xuegecar_bringup        # 运动控制（cmd_vel → micro-ROS → 电机）
├── xuegecar_camera         # 摄像头（HTTP 流 → ROS2 话题）
├── xuegecar_cartographer   # SLAM 建图
├── xuegecar_navigation2    # 导航（Nav2 + EKF + 预置地图 room.yaml）
├── xuegecar_qt_gui         # GUI（摄像头/激光/地图/速度/目标）
├── xuegecar_description    # URDF 模型
├── xuegeros_demo           # 一键启动
├── camsense_lidar          # 激光雷达驱动
├── ydlidar_ros2_driver     # YDLIDAR 驱动
├── slam_gmapping           # 建图
└── openslam_gmapping
```

## 二、启动流程（bringup_all.launch.py）

```
1. Socat：UDP 8889 → /dev/lidar（激光雷达虚拟串口）
2. Micro-ROS Agent：udp4 :8888（连接 ESP32）
3. YDLIDAR 驱动（延迟5s，等 /dev/lidar）
4. xuegecar_bringup（延迟7s，运动控制）
5. 摄像头（HTTP 流）
6. 导航/SLAM/GUI
```

## 三、通信架构

```
┌─ ESP32 (leap_low) ─────────────┐
│  micro-ROS Client（UDP 8888）  │
│  电机/编码器/PID/激光/IMU      │
└──────────────┬─────────────────┘
               │ micro-ROS Agent (udp4:8888)
┌──────────────┴─────────────────┐
│ PC 上位机 (ROS2 Humble)        │
│  运动控制/导航/SLAM/GUI/检测   │
└────────────────────────────────┘
        ┌────────────────────┐
ESP32 (leap_cam) ──HTTP/MJPEG──→ PC 摄像头话题
```

## 四、关键话题

| 话题 | 内容 |
|---|---|
| /cmd_vel | 速度指令 → 电机 |
| /scan | 激光雷达 |
| /camera/image_raw | 摄像头（YOLO 输入）|
| /odom | 里程计 |
| /map | 地图 |
| /goal_pose | 目标点 |

## 五、摄像头（YOLO 关键）

- **http_video_publisher**：拉取 ESP32 MJPEG 流 → 发布 /camera/image_raw
- **参数**：url / topic / fps / jpeg_quality
- **我们的 YOLO**：订阅 /camera/image_raw → 检测

## 六、导航

- Nav2 + EKF（里程计融合）
- **预置地图**：room.yaml / room1.yaml / room2.yaml
- slam_nav2.launch.py（建图+导航一体）

## 七、实机启动步骤（操作手册）

```bash
# 1. 进入工作空间
cd xuegeros_ws
source install/setup.bash

# 2. 一键启动（雷达+micro-ROS+运动控制）
ros2 launch xuegeros_demo bringup_all.launch.py

# 3. 启动摄像头
ros2 launch xuegecar_camera http_video_publisher.launch.py url:=<ESP32摄像头地址>

# 4. 启动导航
ros2 launch xuegecar_navigation2 navigation2.launch.py

# 5. GUI
ros2 launch xuegecar_qt_gui xuegecar_qt_gui.launch.py
```

## 八、我们要加的（三任务/YOLO/语音）

```
订阅 /camera/image_raw → YOLO 检测
订阅 /scan → SLAM/导航
发布 /goal_pose → 目标导航
micro-ROS → 底层控制
+ 语音/VLA → 三任务
```
