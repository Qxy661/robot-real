# 实机视觉方案 · K230 AI 摄像头

> 记录：2026-08-04。客服确认可外接 K230 等，规划 K230 视觉方案。

## 一、K230 能力（调研确认）

**嘉楠 K230 AI 开发板**（249 元）：
```
6TOPS NPU（KPU）
双核 RISC-V（1.6GHz + 800MHz）
3 路 MIPI CSI 摄像头（4K）
H.264/H.265 编解码
5×UART / I2C / PWM / GPIO / 40Pin
YOLOv5s 38fps @INT8
MicroPython / CanMV / Linux + RTOS
```

**关键**：K230 能**车载直接跑 YOLO**（NPU 推理），不是只传图像。

## 二、视觉方案对比（更新）

| 方案 | 说明 | 可行性 |
|---|---|---|
| **A：复用控制板接口** | 客服确认接口 → 加摄像头模组 | 待客服 |
| **B：独立 USB 摄像头** | 插上位机 → OpenCV → YOLO | ✅ 最稳 |
| **C：K230 车载 AI** | **K230 + NPU 跑 YOLO → 串口给小车** | ✅✅ **最优** |

**推荐方案 C（K230）**：
- 车载 AI 视觉（不占 PC 资源）
- K230 直接 YOLO → 结果通过串口/网络给小车
- 体现**边缘 AI 部署**（NPU 推理）——作品集亮点

## 三、K230 视觉架构

```
┌─ K230（车载 AI 视觉）─────────────┐
│  摄像头采集 → KPU YOLO 推理       │
│  → 检测结果（目标/坐标）           │
└──────────┬─────────────────────────┘
           │ 串口/UART / 网络
┌──────────┴─────────────────────────┐
│ 小车（ESP32 + PC）                │
│  接收检测结果 → 决策/导航          │
└────────────────────────────────────┘
```

## 四、K230 接入方式

### 方式 1：串口连接小车
```
K230 UART ↔ ESP32 UART
K230 发检测结果（串口）→ 小车决策
```

### 方式 2：网络（WiFi/UDP）
```
K230（板载 WiFi）→ UDP → PC/小车
检测结果实时传输
```

### 方式 3：K230 独立（视觉 + 决策）
```
K230 跑 YOLO + 简单决策（MicroPython）
→ 直接控制（GPIO/串口）
```

## 五、YOLO 模型部署（K230）

```
训练（PC）→ ONNX → nncase 转换 → K230 KPU 部署
```

### 流程
```
1. PC 训练 YOLO（我们的 M2 经验）
2. 导出 ONNX
3. nncase 编译（K230 格式）
4. K230 部署（MicroPython/CanMV）
5. 实机推理（38fps）
```
