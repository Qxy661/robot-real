# 实机运动与导航配置（源码深挖）

> 基于 xuegeros_ws 源码深挖（2026-08-04）。实机运动/导航的实现细节。

## 一、小车模型（URDF）

**双轮差速小车**：
```
base_footprint → base_link（底盘）
  ├── laser_frame（激光雷达，固定）
  ├── imu_link（IMU，固定）
  ├── left_wheel_link（左轮，continuous）
  └── right_wheel_link（右轮，continuous）
  └── caster_link（万向轮）
```

**坐标框架**：map → odom → base_footprint → base_link

## 二、运动控制（xuegecar_bringup）

**功能**：订阅 /odom → 发布 odom→base_footprint TF
```
odom_subscribe_ → odom_callback（存里程计）
publish_tf → 广播 odom→base_footprint
```

**底层**：/cmd_vel → micro-ROS → ESP32 电机（PID）

## 三、导航配置（nav2.yaml）

**机器人参数**：
```
robot_radius: 0.1（机器人半径）
controller_frequency: 10.0
controller_plugins: FollowPath
```

**代价地图**：
```
inflation_layer:
  inflation_radius: 0.2
  cost_scaling_factor: 3.0
```

**预置地图**：room.yaml / room1.yaml / room2.yaml（PGM）

## 四、摄像头（YOLO 关键）

**http_video_publisher** 参数：
```
url: <ESP32摄像头地址>（必填）
topic: /camera/image_raw/compressed
raw_topic: /camera/image_raw
frame_id: camera_link
fps: 30.0
jpeg_quality: 80
use_ffmpeg: true
publish_raw: false
```

**YOLO 接入**：订阅 /camera/image_raw → 检测

## 五、EKF 定位（robot_localization）

```
frequency: 30.0
two_d_mode: false
map_frame: map
odom_frame: odom
base_frame: base_link
融合：里程计 + IMU
```

## 六、完整启动流程（实机）

```bash
# 1. 一键启动（雷达+micro-ROS+运动控制）
ros2 launch xuegeros_demo bringup_all.launch.py

# 2. 摄像头（需 ESP32 地址）
ros2 launch xuegecar_camera http_video_publisher.launch.py url:=<ESP32>

# 3. 导航
ros2 launch xuegecar_navigation2 navigation2.launch.py

# 4. GUI
ros2 launch xuegecar_qt_gui xuegecar_qt_gui.launch.py

# 5. 预置地图导航
ros2 launch xuegecar_navigation2 navigation2.launch.py map:=room.yaml
```

## 七、我们要加的（三任务）

```
订阅 /camera/image_raw → YOLO（M2）
订阅 /scan → SLAM/导航（M5）
发布 /goal_pose → 目标导航
/cmd_vel → micro-ROS 控制（底层）
+ 语音/VLA → 三任务（IDEA 1-3）
```

## 八、关键确认

1. **YOLO 可行**：摄像头流进 ROS2 话题，PC 检测
2. **导航可行**：Nav2 + 预置地图 + EKF
3. **运动可行**：cmd_vel → micro-ROS → 电机
4. **三任务可落地**：能力都具备
