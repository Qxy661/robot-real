## 三、环境准备（Ubuntu）

```bash
# 1. 装 micro-ROS Agent
sudo apt install ros-humble-micro-ros-agent

# 2. 下载 xuegeros_ws（上位机功能包）
git clone https://github.com/czu963889306-dev/-ros2-.git
# 解压 软件/1.源码/xuegeros_ws.zip 到工作空间

# 3. 编译
cd xuegeros_ws
colcon build
source install/setup.bash
```

## 四、网络配置（手机热点）

```
手机热点
  ├── Ubuntu（连热点）
  └── 小车 ESP32（连热点）
→ 同一局域网，IP 互通
```

```bash
# 1. Ubuntu 连手机热点
# 2. 小车连同一热点（Web 后台配置 WiFi）
# 3. 确认小车 IP（Web 后台看）
# 4. Ubuntu ping 小车 IP 确认连通
```

## 五、micro-ROS 通信

```bash
# 启动 micro-ROS Agent（连接小车 ESP32）
ros2 run micro_ros_agent micro_ros_agent udp4 --port 8888

# 确认话题
ros2 topic list   # 应看到 /odom /imu /scan /cmd_vel
```

## 六、建图（当前重点）

```bash
# 1. 一键启动（雷达 + micro-ROS + 运动控制）
ros2 launch xuegeros_demo bringup_all.launch.py

# 2. 遥控小车走一圈（Web 中控 / 键盘 teleop）

# 3. Cartographer 建图
ros2 launch xuegecar_cartographer cartographer.launch.py

# 4. 保存地图
ros2 run nav2_map_server map_saver_cli -f ~/map/room
```

## 九、依赖链（手册确认）

```
固件/网络 → micro-ROS通信 → 底盘/odom/imu → 雷达/scan
```

## 十、注意事项

- 小车和 Ubuntu **同一 WiFi**（热点）
- micro-ROS Agent 端口 8888（默认）
- 建图前确认 /scan 正常（雷达旋转）
- 导航空旷场地（防激光受玻璃/反光影响）
