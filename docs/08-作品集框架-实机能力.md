# 08 · 实机作品集框架 · 能力分层

> **从仿真到真机，从算法到系统。** 实机是 vla-roadmap「感知→规划→控制→执行」全链路的集大成者。
> 本框架把实机能力组织为**四个递进层次**，每层都有**量化成果**支撑——让作品集有深度、有质量。

## 🎯 核心叙事

```
能控制（死推算/控制论）→ 能感知（传感器专项）→ 能规划（手写算法真机）→ 能系统（整合闭环）
       底层功底               感知可靠性            差异化王牌                全栈能力
```

> **作品集质量 = 每一层都有量化数据**：误差曲线、对比表、覆盖率曲线，而不是"能跑"。

## 📊 能力金字塔（四层递进）

```
┌─────────────────────────────────────────────┐
│  ④ 系统层：整合闭环（巡检/巡逻/语音/中控台）    │  ← 作品集门面
├─────────────────────────────────────────────┤
│  ③ 规划层：手写算法真机（DWA/A*/前沿探索）      │  ← 差异化王牌
├─────────────────────────────────────────────┤
│  ② 感知层：传感器专项（超声波/激光 SLAM）       │  ← 感知可靠性
├─────────────────────────────────────────────┤
│  ① 控制层：死推算与控制论（标定/PID/融合）      │  ← 底层功底
└─────────────────────────────────────────────┘
```

## 🏗️ 各层项目（含量化产出）

### ① 控制层 · 死推算与控制论（先做，打基础）

| 项目 | 方法 | 量化产出 | 状态 |
|---|---|---|---|
| **里程计标定** | 实测 vs 报告值 → 标定轮距/半径 | 误差从 X% → <0.5% 对比 | ⏳ 规划 |
| **PID 精确行驶** | 编码器闭环，精确走 N 米停 | 超调/稳态误差/整定曲线 | ⏳ 规划 |
| **IMU+里程计航向融合** | 互补融合（编码器漂移 vs IMU 偏置）| 融合前后航向误差对比 | ⏳ 规划 |

### ② 感知层 · 传感器专项

| 项目 | 方法 | 量化产出 | 状态 |
|---|---|---|---|
| **超声波定距停车** | 超声波闭环，距障碍 N cm 停 | 距离精度 ±X cm | ⏳ 规划 |
| **超声波避障** | 反应式避障（近距冗余）| 避障成功率 | ⏳ 规划 |
| **激光 SLAM 建图** | Cartographer 实机建图 | 地图覆盖/清晰度 | 🔄 进行中 |

### ③ 规划层 · 手写算法真机（差异化核心）

| 项目 | 方法 | 量化产出 | 状态 |
|---|---|---|---|
| **手写 DWA 真机避障** | path-planning 的 DWA 上真机 | 与 Nav2 对比表（路径/耗时/成功率）| ⏳ 规划 |
| **手写 A* 作为 Nav2 规划器** | 插件化接入（Nav2 pluginlib）| 配置即切换 + 真机路径 | ⏳ 规划 |
| **frontier 自主探索** | 无需遥控自动建图 | 覆盖率 vs 时间曲线 | ⏳ 规划 |

### ④ 系统层 · 整合闭环（作品集门面）

| 项目 | 方法 | 量化产出 | 状态 |
|---|---|---|---|
| **三任务递进** | 巡检→巡逻→语音 | 完整闭环视频 | ⏳ 规划 |
| **自定义中控台** | 改造 ros2_web 成自己版本 | Web 产品 + 特色功能 | ⏳ 规划 |

## 🗺️ 执行路线（按层推进）

```
① 控制层（标定→PID→融合）   ← 最底层，先做，立即出量化成果
② 感知层（超声波→SLAM）     ← 当前：SLAM 建图中
③ 规划层（DWA→A*→探索）    ← 差异化，衔接 path-planning
④ 系统层（三任务→中控台）    ← 作品集门面，最后整合
```

## 🔗 与 vla-roadmap 主线融合

```
M2 检测 → 实机 YOLO（摄像头到位后）
M5 导航 → 手写 DWA/A* 上真机（规划层）
M6 控制 → PID/标定/融合（控制层）
M3 VLA  → 语音指令（三任务 IDEA 3）
```

## 📋 素材要求（每层都要有）

- **量化对比图**：误差曲线 / 对比表 / 覆盖率曲线
- **实机视频**：每层至少一个（控制/感知/规划/系统）
- **踩坑记录**：每层遇到的真机问题与解决

## ✅ 作品集质量检查

- [ ] 每层都有 ≥1 个**量化成果**（误差/对比/曲线）
- [ ] 至少 1 个**手写算法真机部署**（差异化）
- [ ] 至少 1 个**自主性应用**（frontier 探索）
- [ ] 完整闭环视频（感知→规划→控制→执行）
- [ ] 风格统一（与 path-planning 一致）
