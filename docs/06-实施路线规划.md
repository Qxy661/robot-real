# 实机小车实施路线规划

> 定位：robot-real（独立核心仓库）——从感知到执行的集大成者。
> 三任务递进：巡检（能做事）→ 巡逻（会自主）→ 语音（懂人话）。

## 一、实施路线（按依赖链）

```
阶段0 实机准备 → 阶段1 基础通信 → 阶段2 建图导航
→ 阶段3 三任务 → 阶段4 K230视觉 → 阶段5 作品集
```

### 阶段 0：实机准备（当前）

### 阶段 1：基础通信（实机到手）
```

```
