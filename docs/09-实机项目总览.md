# 09 · 实机项目总览 · 整体工作分解

> **robot-real 的"作战地图"**：先看清整体要做哪些，结构清晰 → 再逐块规划 → 逐个击破。
> 一句话定位：**从仿真到真机**，用 LEAP 小车完成「感知 → 规划 → 控制 → 执行」全链路闭环，每个环节都产出**可量化的作品集成果**。

## 一、整体架构（一张图）

```
        【主线叙事】 能做事（巡检）→ 会自主（巡逻）→ 懂人话（语音）
                                   ▲
┌─────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────┤
```

## 四、依赖链与执行顺序

```
基础层 → 能力层(控制→感知→规划) → 三任务 → 深化层(C→B→D) → 呈现层
```

**推荐逐个击破的顺序**（每个都是独立可验收的小里程碑）：
1. **跑通基础层**（micro-ROS + 建图导航）← 当前
2. **控制层三项**（标定→PID→融合，脚本就绪，上真机出数据）
3. **深化 C：检测导航闭环**（最快见效的差异化）
4. **感知专项**（超声波固件放开 → 定距/避障）
5. **三任务 1 → 2 → 3**
6. **深化 B：手写 DWA 真机**（控制层做底）
7. **呈现层**（边做边收集素材，最后统一门面）

## 六、怎么"逐个击破"（执行原则）

1. **一次只攻一个**：每轮选一个小里程碑（如"控制层上真机出标定数据"），完成 + 留素材再进下一个
2. **先数据后美观**：先拿到量化结果，再花时间美化展示
3. **边做边沉淀**：每个项目完成即写进对应 README + 更新本文档状态表
4. **素材即插即用**：量化图/视频按 呈现层 清单收集，最终统一成作品集
